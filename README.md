# Storyly - Tamil + English Bilingual Story Reading App

Storyly is a simple, distraction-free Tamil + English bilingual story reading app built with Flutter. Designed to help users enjoy engaging stories while enhancing their English and Tamil reading comprehension and language skills.

---

## Key Features

* **Bilingual Reading Modes**: Read stories in English, Tamil, or Bilingual Mode (side-by-side / toggle view).
* **Discover by Category**: Explore stories organized by genre, theme, and reading level.
* **Favorites & Saved Stories**: Easily bookmark your favorite stories for quick access.
* **Continue Reading**: Auto-save reading position so you can pick up right where you stopped.
* **Distraction-Free UI**: Clean, modern, and uncluttered interface optimized for reader focus.

---

## Built With

* **Framework**: Flutter (Dart)
* **Target Platforms**: Android & iOS

---

## Getting Started

### Prerequisites
* Flutter SDK (Latest Stable Version)
* Android Studio / VS Code with Flutter extension
* Android Emulator or physical device

### Installation & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/storyly.git
   cd storyly
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the application**:
   ```bash
   flutter run
   ```
